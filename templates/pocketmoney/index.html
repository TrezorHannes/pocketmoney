PocketMoney
Recurring Allowances & Disbursements

PocketMoney automates scheduled Lightning disbursements for weekly allowances, contractor payroll, and recurring server bills.

Core Highlights
  • ⚡ Universal Recipient: Accepts internal LNbits Wallet IDs, Lightning Addresses (alice@getalby.com), and LNURL-pay.
  • 🔄 Zero Routing Fees Internally: Internal peer transfers settle off-chain instantaneously with 0 routing fees without needing child invoice keys.
  • 🛡️ Fail-Closed Safety: If the funding wallet balance is insufficient, payments fail safely with an alert instead of executing partial debits.
  • 💱 Multi-Currency JIT: Send in EUR, USD, GBP, or sats with just-in-time exchange rate conversion at execution time.
  • 🤖 Proactive Alerts: Instant Telegram delivery for completions, slippage skips, and low-balance warnings.
Version: v0.1.1
1. Select Funding Wallet
Use the Funding Wallet dropdown at the top right to choose which LNbits wallet will fund the scheduled payments.
2. Create a Disbursement Plan
Click + New Plan. Give the plan a name (e.g. Kids Weekly Allowance) and choose a recurrence schedule (Daily, Weekly, Monthly, or custom Cron).
3. Add Recipients
Add one or more recipients per plan:
  • 👛 Internal Wallet: Pick a child or peer wallet under your account. Zero routing fees and instant settlement.
  • ⚡ Lightning Address / LNURL: Enter any user@domain.com or LNURL-pay string.
Choose the amount and currency (e.g. 5.00 EUR or 5,000 sats).
4. Budget Ceilings & Alerts
Set an optional Max Satoshis Limit to guard against sudden Bitcoin price fluctuations when paying fiat amounts. Add a Low Balance Alert threshold to be warned before funds run out.
5. Triggers & Automations
Plans run automatically on schedule via LNbits background task. You can also:
  • Click ▶ Run Now for immediate on-demand execution.
  • Click 🧪 Simulate to verify live conversion rates and recipient validity without debiting sats.
  • Copy the 🔗 Webhook URL to trigger the plan from Home Assistant, Cron, Zapier, or shell scripts.
6. Telegram Bot Notifications
Open the Settings & Alerts tab to configure your Telegram bot token and chat room ID. Test your setup with the Send Test Alert button.
